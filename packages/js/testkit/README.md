# @openreceive/testkit

Internal fake NWC wallet and swap provider used by OpenReceive's own test suite. This package is private and unpublished: it is not on npm, and its API may change at any time without notice. The fixtures it mints are a cross-engine contract, written down in [docs/internal/testkit-contract.md](../../../docs/internal/testkit-contract.md). A public guide to testing host integrations is planned separately.

Part of [OpenReceive](https://openreceive.org). Start with the [Node quickstart](https://github.com/openreceive/openreceive/blob/master/docs/guides/quickstart-node.md); the full API is in the [API reference](https://github.com/openreceive/openreceive/blob/master/docs/guides/api-reference.md).
